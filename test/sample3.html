📖 Crypt Browser 使用指南

完整的加密文档浏览器使用说明

🚀 快速开始

步骤 1: 准备加密压缩包

首先，您需要创建一个包含HTML文档的加密7z压缩包：

7z.exe a -sfx -pMyPassword documents.exe .\files\*

这将创建一个自解压的加密压缩包，密码为 "MyPassword"。

步骤 2: 启动程序

通过命令行启动 Crypt Browser，指定压缩包路径：

crypt-browser.exe "C:\path\to\documents.exe"

或者直接将压缩包拖拽到程序图标上。

步骤 3: 输入密码

程序会弹出密码输入对话框，输入正确的密码后点击确定。

[密码输入对话框截图位置]
安全的密码输入界面

步骤 4: 浏览文档

解压完成后，会自动显示美观的目录页面，点击任意文件即可打开。

🎛️ 主要功能

🔐 安全解压

支持密码保护的7z格式，确保文档安全

📁 智能目录

自动生成美观的HTML目录页面

🖥️ 多窗口

每个文档独立窗口，支持多文档同时浏览

🧹 自动清理

程序退出时自动清理所有临时文件

⌨️ 快捷操作

目录页面

  • 点击文件名：在新窗口中打开文档
  • F5：刷新目录页面
  • Ctrl+W：关闭当前窗口

文档窗口

  • ← / →：前进/后退
  • F5：刷新页面
  • Ctrl+Plus / Ctrl+Minus：缩放页面
  • Ctrl+0：重置缩放

🛠️ 高级设置

支持的文件格式

  • .html - 标准HTML文档
  • .htm - HTML文档（短扩展名）
  • .mhtml - 单文件网页存档
  • .mht - Microsoft HTML存档
💡 提示： MHTML格式特别适合保存完整的网页（包括图片、CSS等），推荐用于需要离线浏览的复杂网页。

压缩包创建命令详解

# 基本命令格式
7z.exe a [选项] 输出文件名 输入文件

# 常用选项：
-sfx # 创建自解压文件
-p[密码] # 设置密码
-mx9 # 最高压缩率
-y # 自动确认所有提示

# 示例：创建最高压缩率的加密自解压包
7z.exe a -sfx -pSecretPass -mx9 -y archive.exe .\documents\*

🔧 故障排除

常见问题

Q: 提示"无法启动7z.exe"

A: 请确保已安装7-Zip并将其添加到系统PATH环境变量中。

Q: 密码正确但解压失败

A: 检查压缩包是否损坏，或尝试使用不同的压缩格式。

Q: 页面显示乱码

A: 确保HTML文件使用UTF-8编码保存。

🛡️ 安全建议：
• 使用强密码保护您的压缩包
• 定期更换密码
• 在使用完毕后立即关闭程序
• 避免在不安全的网络环境中使用
